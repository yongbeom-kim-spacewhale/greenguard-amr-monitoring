# GreenGuard — AMR 스마트팜 안전 모니터링

TurtleBot4, AI 인식, Web/DB를 연결해 병든 작물 감지와 침입자 대응 시나리오를 구현한 ROS 2 시스템 통합 프로젝트입니다.

[시연 영상](https://drive.google.com/file/d/1r9bpvAV6bQ-7X2AgRfBYn_sL5UoxdXag/view)

## 프로젝트 정보

- 기간: 2026.06.17–2026.06.30
- 인원: 7명
- 역할: PM·팀장, 시스템 설계, 일정·요구사항 관리, 통합 테스트
- 기술: ROS 2, TurtleBot4, Nav2, SLAM, YOLO, Flask, SQLite3

## 담당 범위

- 프로젝트 일정과 파트별 책임·완료 조건 관리
- AMR, AI, Web/DB의 PC별 역할과 데이터 흐름 정리
- 최종 발표의 3개 End-to-End 시나리오와 모드 전환 조건 정의
- 오전·오후 진행 상황 확인과 산출물 기반 점검
- 완성된 기능의 통합 테스트, 시연 검증과 발표자료 구성

세부 AI·AMR·Web 코드는 각 담당 팀원이 구현했습니다.

## 문제 해결

코드리뷰에서 AMR의 개별 기능은 대부분 완성됐지만 전체 시나리오로 통합되지 않은 상태를 확인했습니다. 최종 시연 순서, 시작 이벤트, 순찰·추적·서치·복귀 조건을 사용자 관점의 흐름으로 다시 정리하고 시스템 설계도를 갱신했습니다.

## 결과

- 순찰·작물 이상 감지
- 침입자 감지·추적·서치·복귀
- 순찰 중 침입자 이벤트에 따른 모드 전환

위 3개 시나리오가 시작부터 종료·복귀까지 이어지는 것을 통합 테스트와 영상으로 확인했습니다. 장시간 안정성과 다양한 환경에서의 정량 성능은 추가 검증 과제로 남았습니다.
